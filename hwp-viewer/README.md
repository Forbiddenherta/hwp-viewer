# 한글 문서 편집기

광고 없이 브라우저에서 HWP/HWPX 문서를 열고 편집하는 개인용 웹 앱입니다.

## 현재 상태

Phase 0 진행 중입니다. `@rhwp/editor` 임베드 방식으로 HWP/HWPX 읽기·편집·저장 기능을 검증하고 있습니다. 이 앱은 서버로 파일을 업로드하지 않는 클라이언트 측 사용을 목표로 합니다.

## 실행

```bash
npm install
npm run dev
```

## 주의

- HWP, HWPX, 한글 및 한컴은 한글과컴퓨터의 등록 상표입니다. 이 프로젝트는 한글과컴퓨터와 무관한 독립 개인 프로젝트입니다.
